## 已决定

### 独立存储空间

应用存储统一使用 `ai-image-studio` 标识，不读取、迁移或回退到旧项目的数据库及存储键，也不主动删除旧数据库和存储键。存储与备份结构由本 fork 独立维护，保留外部输入所需的校验。

### 不要 Agent 模式

应用只保留画廊工作流，彻底移除 Agent 的对话、分支、工具编排、网络搜索、独立配置及相关界面和存储。不保留隐藏开关或兼容实现，不跟进或恢复上游 Agent 功能。画廊使用的 Images API、Responses API、多供应商、参考图、遮罩、画板和批量生成继续保留。

此次移除允许重置 AI Image Studio 的全部本地数据：IndexedDB 从版本 3 升至 4，首次升级时重建任务、图片和缩略图仓库；本地状态从版本 2 升至 3，旧版本直接恢复默认值。后续刷新正常保留新数据。ZIP 备份格式升至 4，仅支持新版备份，不兼容旧备份。此决定覆盖本 fork 旧版数据结构与备份格式沿用约定，不涉及原项目的存储空间。

### 不要桌面客户端

不引入、不恢复上游 v0.8 的 Windows 客户端。包括 `src-tauri`、安装包、自绘标题栏、应用内更新、系统代理、数据目录、SQLite 与图片文件存储、由 Rust 发请求、MCP 服务。原因是维护者明确不要桌面端，而 v0.8.0 到 v0.8.4 混在同一条 `main` 上，不能整支合并。

### 不要 CLI 与 Skill

上游 v0.8.2 的 CLI `gpt-image-playground` 和随附 Skill，是给 Claude Code、Codex 等本机工具用的。它操作的是正在运行的 Windows 客户端：应用必须开着，生图、历史和设置才会进那个客户端。安装入口也在客户端的「设置 → Skill」。

所以它不是一条能单独搬进网页版的能力，随客户端一起拒绝。

### 去掉赞助和推广

已移除应用内赞助入口、赞助弹窗及其状态和触发逻辑，删除 README 中的商业推广与赞助支持区块，以及仓库内的推广预置文件。只删推广，不删功能，保留供应商接入、配置导入、用户已有数据、非商业链接和来源与许可声明。
